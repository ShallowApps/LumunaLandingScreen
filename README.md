# Lumuna – Landing

Single-page static site for [lumuna.app](https://lumuna.app). No build step.

- `/` home
- `/#privacy` privacy policy
- `/#terms` terms of use
- `/#support` support & FAQ

Contact: contact@shallowapps.com

## Hosting

Ready for GitHub Pages: `CNAME` points at `lumuna.app`, `.nojekyll` serves files as-is.
In repo Settings → Pages, deploy from `main` / root, then add the DNS records GitHub shows.
